Install

  1. Install Prism Launcher on the computer you play on, and sign in with your Microsoft account.
  2. In Prism choose Add Instance → Import, and paste your link.
  3. Launch it. The first launch downloads everything; after that it updates itself each time.

Import links only work while Tailscale is connected. Your own settings are never overwritten.

Hotkeys

KTurn shaders on or off (shader tiers)
CZoom (hold)
MWorld map
BNew waypoint

Forward mouse buttonPing a spot for everyone to see
