Yossarian Modpacks

Minecraft 26.3, Fabric 0.19.5.

Install

  1. Install Prism Launcher on the computer you play on, and sign in with your Microsoft account.
  2. In Prism choose Add Instance, then Import, and paste the link for your tier below.
  3. The first time: launch it, quit, then launch it again. The first launch downloads the mods; the second is the one where everything is in place.
  4. After that, just play. It updates itself each time you launch.

Press k to toggle shaders on/off.

You can import more than one tier. Each becomes its own instance in Prism, so you can switch between them, for example to compare Ultra with Live. Each instance keeps its own settings and maps.

Import links only work while Tailscale is connected, the same as for joining the server. Reading this on a phone? Open it on your computer to install, since Prism runs there. Your own settings are never overwritten.

Tiers

  • Yossarian - macOS (Basic)

    No shaders, Vulkan renderer. The smoothest option on a Mac.

    http://yossarian.tail40a095.ts.net:8101/instances/Yossarian-macOS-Basic.zip

  • Yossarian - macOS (Shaders)

    Complementary shaders on Medium. Uses OpenGL, because shaders can't run on Vulkan.

    http://yossarian.tail40a095.ts.net:8101/instances/Yossarian-macOS-Shaders.zip

  • Yossarian - macOS (Shaders, Megan) Megan Start Here

    macOS Shaders with clear, light water you can see well into, and no wobble underwater.

    http://yossarian.tail40a095.ts.net:8101/instances/Yossarian-macOS-Shaders-Megan.zip

  • Yossarian - Windows (Basic)

    No shaders. The fallback for weaker PCs, or if shaders won't run.

    http://yossarian.tail40a095.ts.net:8101/instances/Yossarian-Windows-Basic.zip

  • Yossarian - Windows (High) Morgan Start Here

    Complementary High, 16-chunk view. For lighter gaming PCs (RX 7600 XT class).

    http://yossarian.tail40a095.ts.net:8101/instances/Yossarian-Windows-High.zip

  • Yossarian - Windows (High, Megan) Megan Start Here

    High with clear, light water you can see well into, and no wobble underwater.

    http://yossarian.tail40a095.ts.net:8101/instances/Yossarian-Windows-High-Megan.zip

  • Yossarian - Windows (Very High) Luis Start Here

    Complementary Very High, which adds colored light from torches and lava, with a 20-chunk view (RX 6800 XT class).

    http://yossarian.tail40a095.ts.net:8101/instances/Yossarian-Windows-Very-High.zip

  • Yossarian - Windows (Ultra)

    Complementary Ultra, which adds reflections of off-screen terrain in water and glass, with a 24-chunk view (RTX 4070 Ti Super class).

    http://yossarian.tail40a095.ts.net:8101/instances/Yossarian-Windows-Ultra.zip

  • Yossarian - Windows (Ultra Unbound)

    Ultra with Complementary Unbound instead of Reimagined: more realistic lighting, clouds and water, and a little heavier.

    http://yossarian.tail40a095.ts.net:8101/instances/Yossarian-Windows-Ultra-Unbound.zip

  • Yossarian - Windows (Fuck It, We'll do it Live - Reimagined)

    Everything turned up: Complementary's top profile, 32-chunk view, Distant Horizons out to 512 chunks at Extreme detail. Aims for 70-100 FPS on an RTX 4070 Ti Super.

    http://yossarian.tail40a095.ts.net:8101/instances/Yossarian-Windows-Fuck-It-Well-do-it-Live-Reimagined.zip

  • Yossarian - Windows (Fuck It, We'll do it Live - Unbound)

    The same as Live, with Complementary Unbound's more realistic look. The heaviest tier.

    http://yossarian.tail40a095.ts.net:8101/instances/Yossarian-Windows-Fuck-It-Well-do-it-Live-Unbound.zip
